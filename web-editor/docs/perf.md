# 성능 측정

샌드박스 측정 불가 — GPU가 없어 재생·내보내기 속도가 사용자 노트북을 대표하지 못한다. 성능은 사용자가 Windows 노트북에서 내보내기 창에 표시되는 시간으로 확인한다.

## 사용자 노트북 확인 결과
| 시점 | 조건 | 소요 시간 |
|------|------|-----------|
| 확인 2 (1단계) | 60초 1080×1920, 효과 없음 | 통과 — **미기입** (전달받은 칸이 비어 있었다) |
| 확인 3 (2단계) | 60초 1080×1920, 필터·효과 포함 | 통과 — **미기입** (전달받은 칸이 비어 있었다) |

두 번 모두 사용자가 "통과"로 판정했고, 숫자만 받지 못했다. 알려 주면 이 표를 채운다.
