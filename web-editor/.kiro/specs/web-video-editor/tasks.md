# 태스크 — 웹 영상 편집기

목표: 쇼츠·릴스 홍보 영상 편집에서 캡컷 데스크톱과 같은 사용감 + "캡컷보다 나은 점" 3가지(무료 로컬 AI, 브랜드 키트, 잠금 없음).

## 공통 규칙
- **작업 범위:** 모든 파일은 `web-editor/` 안에만 만든다. 기존 Python/Electron 앱은 건드리지 않는다.
  예외 하나: 워크플로 파일은 GitHub 규칙상 저장소 루트에 있어야 하므로 `.github/workflows/web-editor-pages.yml`만 쓴다. `web-editor/`만 빌드하고 기존 워크플로는 수정하지 않는다.
- **태스크 완료 조건:** `npm run build` + 단위 테스트 + Playwright(chrome) 통과 → 커밋 → CI 통과 → GitHub Pages 배포 → 접속 주소 보고. 하나라도 실패하면 다음으로 넘어가지 않는다.
- **같은 오류가 두 번 나면** 멈추고 가설 2개를 적어 보고한다.
- **AI 기능(3단계):** 전부 브라우저 안에서 로컬 실행. 유료 API·Google API·외부 API 키를 쓰지 않는다. 모델은 처음 한 번만 내려받아 캐시하고, 내려받는 동안 진행률을 보여 준다.
- **이펙트·필터·트랜지션(2단계):** WebGL 셰이더로 구현한다. 미리보기와 내보내기는 같은 코드를 쓴다(R11.8).
- **캡컷의 이름·로고·에셋은 복제하지 않는다.** 기능과 사용 흐름만 참고한다.
- **⏸ 확인 지점:** 확인 2(태스크 10.5 뒤), 확인 3(2단계 뒤), 확인 4(3단계 뒤). 각 확인마다 "Windows Chrome에서 확인할 시나리오 3줄"을 전달하고, 답을 받기 전에는 다음 단계를 시작하지 않는다.

# 3단계 — 캡컷보다 나은 점 (확인 3 통과 후)

확인한 사실(2026-09-29):
- `@huggingface/transformers` 4.3.0 (Apache-2.0). Whisper 단어별 타이밍은 **`_timestamped`로 내보낸 모델**이 필요하다. `onnx-community`에 tiny/base/small/medium/large-v3-turbo의 `_timestamped` 저장소가 있다(다국어 = 한국어 가능).
- 모델 파일 크기(ONNX 합계, HF API로 측정): tiny q4f16 46MB · int8 101MB / base q4f16 69MB · int8 180MB / small q4f16 146MB · int8 547MB / large-v3-turbo q4f16 564MB · q4 759MB
- `@mediapipe/tasks-vision` 1.0.1 (Apache-2.0). WASM 런타임(34MB)이 npm 패키지에 들어 있어 **직접 호스팅**할 수 있다. `.task` 모델 파일은 패키지에 없으므로 저장소에 넣거나 한 번 받아 캐시한다 → **런타임에 Google 서버를 부르지 않는다**
- 세부 API(`device: 'webgpu'`, `dtype`, `return_timestamps: 'word'` 등)는 태스크 21 스파이크에서 공식 문서로 확인한 뒤 쓴다

- [ ] **21. AI 공통 기반 + Whisper 스파이크**
  - 모델 캐시(Cache API 또는 IndexedDB), 내려받기 진행률 UI, WebGPU 확인 후 WASM 되돌아가기, Worker에서 실행(편집 중단 없음), 취소
